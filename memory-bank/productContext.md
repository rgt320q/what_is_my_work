# Product Context

## 1. Problem Solved

This project addresses the need for a structured, gamified learning path for software developers. It provides a clear, step-by-step progression from junior to master, turning the abstract journey of skill acquisition into a concrete and measurable game. Users can see exactly where they are, what they need to do next, and how their skills are advancing.

## 2. User Experience (UX) Goals

- **Clarity and Progression:** The user should always feel a clear sense of progress. The hierarchy of Specialization > Level > Stage > Task must be visually intuitive.
- **Motivation:** The game loop of completing tasks, earning time, and passing quizzes is designed to be motivating. The ability to overcome failure by repeating specific tasks provides a sense of mastery.
- **Real-World Connection:** Tasks are linked to real-world articles, documentation, and tools via URLs, grounding the game in practical, applicable knowledge.
- **Flexibility:** The settings screen allows users (or administrators) to customize the game's content, such as task durations and URLs, making it adaptable for different learning paces or curricula.

## 3. Core Functionality

- **Task Simulation:** Users "perform" tasks by starting a timer. This simulates the time and focus required for real-world work.
- **Knowledge Verification:** Quizzes at the end of each stage test the user's understanding of the concepts covered in the preceding tasks.
- **Remediation Loop:** The system intelligently identifies knowledge gaps (via failed quiz questions) and directs the user to repeat only the relevant tasks, creating an efficient and targeted learning loop.
- **Career Path Simulation:** The game maps out a full career path from Junior to Master, giving users a long-term view of their potential growth.
